# Design Doc Sources

- [Design Docs at Google](https://www.industrialempathy.com/posts/design-docs-at-google/)
  (Malte Ubl): firsthand description of Google's design doc template and the
  source for this skill's standard sections and tiering guidance (skip the
  doc when there's no real ambiguity; 1-3 pages for small changes).
- [Software Engineering RFC and Design Doc Examples and Templates](https://newsletter.pragmaticengineer.com/p/software-engineering-rfc-and-design)
  and [Companies Using RFCs or Design Docs](https://blog.pragmaticengineer.com/rfcs-and-design-docs/)
  (Gergely Orosz, The Pragmatic Engineer): survey of RFC practice across
  companies, source for the common-denominator RFC shape and the warning that
  required-section creep is the most common failure mode.
- [designdocs.dev](https://www.designdocs.dev/): a curated library of design
  doc examples from real engineering orgs and OSS projects, built by Eraser (a
  commercial design-doc tool). Useful for browsing examples, not a methodology
  source for this skill.
